## 5. Modeling Features

The model uses the following five features:

- `amount`
- `oldbalanceOrg`
- `oldbalanceDest`
- `log_amount`
- `type`

The target variable is `isFraud`.

## 6. Important Evaluation Caveat

Observed fraud prevalence differs substantially across the chronological partitions:

| Partition | Fraud Cases | Fraud Prevalence |
|---|---:|---:|
| Training | 3,643 | 0.081616% |
| Validation | 564 | 0.057527% |
| Test | 4,006 | 0.436090% |

Test-set fraud prevalence is approximately 7.6 times the validation-set prevalence.

Consequently, precision and Average Precision should be interpreted in the context of this distribution shift. The results do not, by themselves, establish performance on real-world banking transactions or prove the cause of the prevalence change.
